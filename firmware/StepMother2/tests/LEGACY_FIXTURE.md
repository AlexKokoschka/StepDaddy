# Legacy save fixture

legacy_v023_flash.bin was generated by the actual supplied merged v0.2.3
StepBro/Yummy adapters and journal while running its original host integration
test. It contains simulated flash and seeded test patterns, not user hardware
pattern data. The only added baseline hook exported the mock flash bytes.
The port's integration test imports it, verifies exact legacy payload restoration
and default Drive, saves the extension, reloads it and rejects unknown tags.
Every 16-bit Drive value is checked for stable decode/encode.

Fixture SHA-256: e0fdb585ae703f531bf810d47a419d20bdc08b75b963eb2b8517227be9e1202e

The original v0.2.3 journal and engine adapters were separately compiled to read
a new Drive-tagged save. That rollback compatibility test passed; its log is
included with the build evidence. The pre-Drive record format is shared by the
supplied Teensy v0.1.0 baseline.
